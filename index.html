Core Capabilities

Complete Feature Set

Everything needed for secure, efficient online examination management across all user roles.

🔐

Secure Authentication

JWT-based authentication with BCrypt password hashing. Role-based access control for Students, Faculty, and Administrators with granular permissions.

📝

Live Exam Interface

Real-time exam taking with server-synced timer, auto-save every 30 seconds, question navigation, bookmarking, and automatic submission on time expiry.

📊

Result Management

Automatic grading for MCQs, manual grading interface for subjective answers, result approval workflow, and detailed performance analytics.

❓

Question Bank

Support for MCQ, True/False, Short Answer, and Essay questions. Difficulty levels, tagging, import/export, and randomization capabilities.

👨‍🏫

Faculty Dashboard

Create and schedule exams, manage questions, review submissions, grade answers, approve results, and view student analytics and reports.

⚙️

Admin Control

Comprehensive user management, department and subject configuration, system settings, audit logs, and detailed analytics reporting.

🔔

Notifications

Real-time notification system for exam schedules, results publication, status changes, and important announcements with history tracking.

📱

Responsive Design

Mobile-first responsive interface works seamlessly on desktop, tablet, and mobile devices. Clean, intuitive UI across all screen sizes.

🚀

Cloud Ready

Docker containerization, Render deployment blueprint, environment-based configuration, SSL/TLS support, and production-ready architecture.

Quick Start (5 Minutes)

# 1. Start Backend (with embedded H2 database) cd parikshaguru-backend/parikshaguru-backend mvn spring-boot:run -Dspring-boot.run.arguments="--spring.profiles.active=h2" # Backend available at: http://localhost:8080
# 2. Start Frontend (in new terminal) cd "ParikshaGuru Frontend" npm install && npm start # Frontend available at: http://localhost:3000
